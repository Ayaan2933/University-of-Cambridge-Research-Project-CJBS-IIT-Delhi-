This folder contains the data files for all the 6 PM2.5 hotspot stations considered in our work, namely Anand Vihar, Punjabi Bagh, ITO, Wazirpur, RK Puram and Jahangirpuri.
All the meteorological variables were retrieved from the ERA5 repository whereas all the pollutant datasets were extracted from the Central Pollution Control Board (CPCB) portal.
